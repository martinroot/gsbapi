API docs

POST /v1/check is intended to check one URL from a single region only. The live endpoint is not active in this preview.

curl https://gsb-api.lol/v1/check \
  -H "Authorization: Bearer $GSB_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: check-001" \
  -d '{"url":"https://example.com/"}'

GET /v1/usage returns your balance and the number of checks billed.

  • warning — Chrome showed a Safe Browsing warning in the single configured region.
  • no_warning_observed — The one configured region completed the check without a warning.
  • check_failed — HTTP 503. The check was inconclusive and costs $0.

Use the same idempotency key when retrying a request after a network interruption.

Tracker sync

Sync domains from Binom or Keitaro with the tracker sync script. Schedule it on the tracker host to refresh its list automatically. Use GET /v1/domains.csv to export all monitored domains.

MCP Agents

Preview status: this route is reserved but not active until the gateway is deployed.

When live, connect to https://gsb-api.lol/mcp over Streamable HTTP. Send your account key in the Authorization: Bearer YOUR_API_KEY header.

  • Claude Code. Add an HTTP MCP server with the URL and authorization header.
  • GPT. Set server_url and headers on the mcp tool in the OpenAI Responses API.
  • Hermes. Set url, headers, and skip_preflight: true under mcp_servers.

Use get_schedule and set_schedule to read or update a check schedule. Use list_domains to see all monitored domains and replace_manual_domains to update the manual list.

Preview only · live scans, signup, billing and MCP are not active.
